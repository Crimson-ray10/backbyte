RULES & DOSSIER

HOW TO PLAY BACKBYTE

BACKBYTE is a social deduction coding game inspired by Among Us, tailored for software developers and problem solvers.

🧑‍💻 DEVELOPERS (CREW):

  • Collaborate on coding tasks in JavaScript and complete functions.
  • Run test suites to raise Team Codebase Health to 100%.
  • Monitor live git commits for unexpected bug injections or mutated logic.
  • Hit EMERGENCY MEETING to discuss, interrogate, and vote out the suspect!

🕵️ THE IMPOSTOR:

  • Blend in! Pretend to write code while covertly destroying tests.
  • Use Sabotage Abilities: Inject Bugs, Blur Editors, and Fake AI Hints.
  • Create confusion during emergency meetings, provide plausible alibis, and frame teammates.

⌨️ TIPS FOR ITCH.IO PLAYERS:

  • Press Tab in the code editor to indent code.
  • Click the Fullscreen (⛶) button on top right to expand the game frame.
  • Use the Quick Replies during meetings or type custom accusations in the chat bar.
